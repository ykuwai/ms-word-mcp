# Security

Please report a vulnerability privately, through
[GitHub's private vulnerability reporting](https://github.com/ykuwai/ms-word-mcp/security/advisories/new),
rather than in a public issue. Say what an attacker can do, and how to
reproduce it.

Only the latest release and the `main` branch are supported. The project is
pre-release, so fixes land there first.

What the server protects against, and what it leaves to you, is in the
[Security section of the README](README.md#security).
